## Overview

Micha Stocks is an AI-powered stock analysis tool that applies trading patterns extracted from 2,500+ YouTube videos. It runs as a Streamlit dashboard on an Intel NUC home server, exposed publicly via Tailscale Funnel. The SQLite database (142MB) is gitignored — it must be restored from backup or rebuilt via the data pipeline.

## Prerequisites

- Intel NUC (or similar Linux server) with network access
- Python 3.10+ and Node.js 18+
- Tailscale account with the NUC enrolled
- OpenCode Go API key (for DeepSeek AI reasoning)
- The SQLite database backup (`micha.db`) — 142MB, not in git

## Step 4: Restore the database

Option A — restore from backup:
```bash

```

Option B — rebuild from scratch (takes many hours):
```bash

node app/scripts/embed.js            # generate embeddings
```

## Known Gotchas

- **The 142MB database is not in git.** A fresh clone needs `app/data/micha.db` from backup. Without it, the app starts but all queries fail.
- **Node.js required for semantic search.** Without `node scripts/embed.js` having run, semantic search falls back to FTS5 keyword search.
- **yfinance can be unstable** for some international tickers — wrap calls in try/except.
- **OpenCode Go rate limits:** V4 Flash: 31,650 req/5h, V4 Pro: 3,450 req/5h. Default to Flash, escalate to Pro only for hard reasoning.
- **Tailscale Funnel URL contains machine name** — if the NUC is renamed, update the public URL in `README.md` and `AGENTS.md`.
- **FTS5 requires a specific SQLite build** — standard Python `sqlite3` includes it; no extra install needed.
